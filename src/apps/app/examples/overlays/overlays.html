Overlays together

Menu, Dialog, Select, Tooltip, Popover and Snackbar in one flow. Open the menu, create a project (the Select list and the Tooltip work inside the dialog), save (the toast over the modal shows no action), then delete a project (confirm dialog, then a toast with an action once the modal is gone). Esc closes one layer at a time and focus returns to where you were.

Project actions

Layers are ordered by opening: the last one opened is on top, and Esc closes only that one.
