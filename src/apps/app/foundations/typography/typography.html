Typography

Default font is JetBrains Mono; a system sans stack is available for body text. Use "Font" in the header to compare. Sizes are in ru, so they grow with the viewport (see Units).

Text styles

Classes from typography.css (loaded by index.css). .shy-sr-only hides text on screen and keeps it for screen readers.

@for (style of textStyles; track style) {
.shy-{{ style }}
Pack my box with five dozen jugs
}

Inline npm run check:ds uses .shy-code. This sentence is only for screen readers.
