Stepper

<shy-stepper> is a progress indicator: an ordered list with one native button per <shy-step> and aria-current="step" on the current one. It has no panels: show your own content from [(value)] (0-based index). Steps before the current one are completed; state is never conveyed by color alone (check, "!" and hidden status text).

Only the current and earlier steps can be clicked; moving forward is up to your code (for example after validating).
