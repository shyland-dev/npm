List

<shy-list> and <shy-list-item> have list semantics. An item can be static, a native link (href) or a native button (interactive, emits activated). Slots: start, secondary and end.

Static, with slots

@for (person of people; track person.id) { {{ person.name }} {{ person.mail }} Active }

Interactive (selected item)

@for (person of people; track person.id) { {{ person.name }} } Disabled item

Selected: {{ selected() }}
