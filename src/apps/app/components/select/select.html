Select

Select-only combobox (APG): focus stays on the button and the active option is announced with aria-activedescendant. The list opens in the overlay layer, flips when there is no room and works inside a dialog. Value through ngModel, formControl or [(value)]. Keys: ↓ ↑ Enter Space open, arrows/Home/End move, typing jumps to a match, Esc closes.

Default with [(value)]

value: {{ selected() }}

In a form field, required

value: "{{ required.value }}", {{ required.valid ? 'valid' : 'invalid' }}

Multiple

Disabled and invalid

Inside a dialog

Token override

Button tokens go on the element: --shy-select-bg, --shy-select-radius. Panel tokens (--shy-select-panel-bg, --shy-select-option-hover-bg) go on :root, because the panel lives in the overlay container.
