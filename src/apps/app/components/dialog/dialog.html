Dialog

DialogService.open() shows <shy-dialog> content in a native modal <dialog>: the page behind is inert, Tab stays inside, Esc closes only the top layer and focus returns to the button that opened it. The title names the dialog (aria-labelledby) and the body describes it. Sizes sm, md, lg and full shrink to the screen width.

Sizes

@for (size of sizes; track size) { }

Inside the dialog: a form field, a scrolling body, a popover anchored in it and a second dialog on top.

Presentation

presentation: 'sheet' sticks the dialog to the bottom edge at full width (respecting the safe area); 'auto' does it only in portrait and keeps it centered in landscape.

@for (presentation of presentations; track presentation) { }

Confirm and alert

confirm() and alert() use role="alertdialog", put focus on the safe button (Cancel / OK) and ignore clicks on the backdrop.
