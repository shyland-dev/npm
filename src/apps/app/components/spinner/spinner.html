Spinner

Activity without known duration: <shy-spinner label="Loading orders" />. Color comes from currentColor. With label it is a role="status" region; without it, it is decorative (aria-hidden). With reduced motion every variant stops moving and only fades (try the Reduce motion toggle).

Color

Inherits the text color; --shy-spinner-color overrides it.

In a button

Button loading uses the ring spinner at the icon size; the button carries aria-busy, so the spinner stays decorative.

Tokens

--shy-spinner-size, --shy-spinner-color. Durations: --shy-duration-loop, --shy-duration-loop-slow, --shy-duration-breathe.
