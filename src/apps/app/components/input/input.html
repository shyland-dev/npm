Input

<input shyInput> styles the native element, so ngModel, formControl and formControlName work as usual. Wrap it in <shy-form-field> for label, hint, error and ARIA wiring. The invalid state is never only a color: the field adds an icon and a message. Sizes: shyInput="sm|md|lg".
