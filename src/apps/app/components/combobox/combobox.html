Combobox

Text field with a list of suggestions (APG combobox with list autocomplete): focus stays on the input and the active option is announced with aria-activedescendant. Same options and value as shy-select, single value, no free text. Typing filters (accent and case insensitive), ↓/↑ move, Enter chooses, Esc closes and restores the text, clearing the text clears the value.

Default with [(value)]

value: {{ selected() }}

In a form field, required

value: "{{ required.value }}", {{ required.valid ? 'valid' : 'invalid' }}

Custom filter and empty text

Disabled and invalid

Tokens

Field tokens go on the element (--shy-combobox-bg, --shy-combobox-radius); panel tokens (--shy-combobox-panel-bg, --shy-combobox-option-hover-bg, --shy-combobox-empty-fg) go on :root, because the panel lives in the overlay container.
