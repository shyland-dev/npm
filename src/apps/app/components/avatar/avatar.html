Avatar

<shy-avatar> shows src; if it is missing or fails to load, it falls back to the initials of name and then to an icon. label (default: name) is the accessible name; without both the avatar is decorative (aria-hidden).

Sizes

@for (size of sizes; track size) { }

Fallbacks

Broken image (initials), name only, single word, and nothing (icon, decorative).
